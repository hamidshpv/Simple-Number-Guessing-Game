# Simple Number Guessing Game

**[🎮 Play the Game Live!](https://hamidshpv.github.io/Simple-Number-Guessing-Game/)**

A simple, interactive web-based game where the player attempts to guess a randomly generated number between 0 and 100. This project was built to practice core web development skills.

## Features
- **Random Number Generation**: A new number is generated every time the game starts.
- **Input Validation**: Ensures the player only enters valid numbers.
- **Real-time Feedback**: Provides instant clues ("Too low!" or "Too high!") to help the player.
- **Win Condition**: Displays the total number of attempts taken upon winning.
- **User-friendly**: Includes automatic input clearing and focus for a seamless experience.

## Technologies Used
- **HTML5**: Structure of the game interface.
- **CSS3**: Styling and layout.
- **JavaScript**: Core game logic and DOM manipulation.

## How to Play
1. Click the [Live Link](https://hamidshpv.github.io/Simple-Number-Guessing-Game/) above to open the game in your browser.
2. Enter a number between 0 and 100 in the input field.
3. Click "Guess!" or press the "Enter" key to submit your guess.
4. Follow the feedback messages until you guess the correct number.
